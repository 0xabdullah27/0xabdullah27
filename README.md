### 👨‍💻 About Me

I build LLM-powered autonomous agents and resilient full-stack systems that execute real-world workflows — featuring tool-calling, strict schemas, and hardened production infrastructure (JWKS auth, AES-256 encryption, vector RAG, and extensive automated test suites). Currently focused on Physical AI, Humanoid Robotics, and Agentic workflows with the OpenAI Agents SDK on top of Next.js and FastAPI foundations.
